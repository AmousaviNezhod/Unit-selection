# UniSel — سیستم پیش‌انتخاب واحد دانشگاهی

ابزار تحت وب برای **پیش‌انتخاب (Pre-selection) واحدهای دانشگاهی** — ساخته‌شده با HTML، CSS و JavaScript خالص (بدون فریم‌ورک، بدون بک‌اند). کاربر دیتای دروس ارائه‌شده را وارد می‌کند، دروس را با فیلترهای پیشرفته جستجو می‌کند و برنامه هفتگی خود را روی جدول زمانی تعاملی می‌چیند؛ سپس برنامه را با دیگران به اشتراک می‌گذارد، مقایسه می‌کند و به هر شکل دلخواه خروجی می‌گیرد.

---

## ✨ امکانات

### 📅 جدول زمان‌بندی

- جدول هفتگی تعاملی (روزها × ساعات ۷ تا ۲۰) با چیدمان RTL
- **بلوک‌های رنگی دروس** با نمایش نام، استاد، ساعت و گروه — هر درس یک رنگ مشخص از پالت می‌گیرد که در جدول، کارت‌های هزینه و همه‌جا قابل تشخیص است
- **انیمیشن دیف‌محور**: هنگام افزودن یا حذف درس فقط بلاکِ تغییرکرده وارد/خارج می‌شود؛ بقیه جدول سر جایش می‌مانند (لایه GSAP با fallback کامل)
- کلیک روی هر بلوک، مودال جزئیات کامل درس را باز می‌کند
- ردیف «سایر دروس» برای دروس بدون ساعت کلاس مشخص (کارآموزی، پروژه و…)
- تشخیص **تداخل زمانی** هنگام افزودن درس با مودال تداخل و امکان خواندن جزئیات
- هشدار عبور از سقف واحد مجاز (۲۰ واحد) روی جدول
- دکمه «کل جدول» (fit mode): جدول تمام‌صفحه با شبکه جابه‌جاشده (ساعت‌ها ردیف، روزها ستون) — مخصوص اسکرین‌شات در موبایل
- **چند برنامه‌ای (تب‌ها)**: هر تعداد برنامه بسازید، کپی و حذف و تغییر نام دهید
  - دسکتاپ: چیپ‌های تب بالای جدول (راست‌کلیک/منو برای تغییر نام)
  - موبایل: همه تب‌ها داخل **یک منوی بازشونده فشرده** جمع می‌شوند تا هدر جدول فضای صفحه را نگیرد

### 🔍 جستجو و فیلتر پیشرفته

- جستجوی زنده بر اساس نام درس، استاد، کد درس یا گروه
- چیپ‌های فیلتر روزهای هفته (چند انتخابی)
- **اسلایدر دو-دستی بازه‌ی زمانی** (Dual-handle range) به‌جای دو اینپوت «از/تا» — با قرص‌های نمایش ساعت
- فیلتر ظرفیت آزاد / ظرفیت پر (متقابل انحصاری)
- فیلتر استاد (لیست خودکار از دیتا)، تعداد واحد (شامل «۳ به بالا»)، و گروه
- مرتب‌سازی نتایج بر اساس نام درس (صعودی/نزولی)
- شمارنده فیلترهای فعال + دکمه حذف همه فیلترها
- **دو شکل ارائه:**
  - دسکتاپ: دراور فیلتر کنار پنل نتایج (همیشه باز، هم‌ارتفاع جدول و قابل اسکرول کامل)
  - موبایل: مودال bottom-sheet با مقیاس لمسی یکدست (چیپ‌ها، سگمنت‌ها و فیلدها هم‌خانواده)

### 🎯 انتخاب درس

- جمع واحدها و تعداد دروس انتخابی به‌صورت زنده
- نمایش ظرفیت هر درس (ثبت‌نام‌شده از ظرفیت) — سبز وقتی جا هست، قرمز وقتی پر است
- دروس با ظرفیت پر قابل انتخاب نیستند (دکمه غیرفعال + بج «ظرفیت پر»)
- ذخیره خودکار همه چیز در `localStorage` — انتخاب‌ها، برنامه‌ها و تنظیمات با بستن مرورگر از بین نمی‌روند
- **Undo / Redo** کامل روی تغییرات برنامه (دسکتاپ: داک؛ موبایل: نوار عملیات)

### ⚙️ ولیدیشن‌های قابل تنظیم (per-program)

هر برنامه (تب) کلیدهای ولیدیشن خودش را دارد و می‌توانید هرکدام را خاموش/روشن کنید:

| قانون | توضیح |
|---|---|
| `capacity` | جلوگیری از انتخاب درس با ظرفیت پر |
| `duplicate` | جلوگیری از اخذ تکراری یک درس (کد یکسان) |
| `conflict` | تشخیص و جلوگیری از تداخل زمانی |
| `units` | هشدار عبور از سقف ۲۰ واحد |

- مودال «تنظیمات ولیدیشن»: سوییچ هر قانون + خلاصه + اعمال/بازنشانی/تأیید
- بج تعداد قوانین خاموش روی چیپ برنامه نشان داده می‌شود
- تنظیمات ولیدیشن با **لینک اشتراک** هم منتقل می‌شوند

### 🗂 دیتای دلخواه

- ورود دیتای جدول HTML پورتال دانشگاه (کپی/پیست مستقیم از سامانه آموزش)
- پارس خودکار: کد درس، گروه، واحد، ظرفیت، استاد و برنامه هفتگی از tooltipهای پورتال
- **گزارش ساختار دیتا**: دروس جدید، دروس تکراری/متفاوت با دیتای قبلی، و تداخل با تب‌های باز
  - انتخاب per-course: درج به‌عنوان «استثنا» از دیتای خود برنامه، یا حذف
- **منشأ درس (origin)**: درسی که از لینک شیر آمده و در دیتای اصلی نیست، در لیست دروس **لیبل‌دار** می‌شود («واردشده از لینک شیر»)
- فعال‌سازی دیتای دلخواه، دیتای پیش‌فرض را قفل می‌کند
- دیتای دلخواه در `localStorage` ذخیره و در اجرای بعدی بازیابی می‌شود

### 💰 هزینه دروس

- جدول هزینه بر اساس **مبلغ واحد هر درس** از `data/couresPrice.html` + جمع کل
- **کارت‌های رنگی موبایل**: به‌جای جدول شلوغ، هر درس یک کارت با رنگ خودش و مبلغ درشت
- **اسکریپت تیک خودکار پورتال**: تولید اسکریپت کنسول که در صفحه پیش‌محاسبه سایت دانشگاه، همه دروس انتخاب‌شده را یکجا تیک می‌زند (با گزینه‌ی Skip خودکار برای تداخل‌ها)

### 🤖 برنامه‌ریزی با هوش مصنوعی

- فرم سه‌مرحله‌ای: دروس پاس‌شده (جستجو و چیپ) ← درس‌های پیش‌نیازی (اختیاری) ← اولویت‌ها و بازه تعداد واحد
- تولید **پرامپت آماده کپی** برای چت‌بات AI — مدل فقط از دروس موجود در دیتای شما انتخاب می‌کند
- انتخاب‌های شما ذخیره می‌شود تا دفعه بعد دوباره شروع نکنید

### ⚖️ مقایسه برنامه‌ها

- مودال مقایسه‌ای برای همه برنامه‌های ذخیره‌شده: تعداد درس، جمع واحد، جمع هزینه، شلوغ‌ترین روزها، دروس مشترک و منحصربه‌فرد
- **مقایسه روی جدول (Overlay)**: برنامه دوم را مستقیم روی جدول خودتان ببینید
  - هر روز **دو لاین**: برنامه شما بالا، برنامه مقایسه پایین با opacity کمتر و بوردر خط‌چین
  - برنامه مقایسه با رنگ متمایز (بنفش) از پالت درس‌ها جدا می‌شود
  - منبع لایه: هر برنامه ذخیره‌شده، **یا لینک شیر دوستتان** (snapshot مستقل از تب فعال)
  - بنر لجند زیر هدر جدول + دکمه «پایان مقایسه»
  - همگام زنده: تغییر نام/محتوای برنامه لایه، شبح‌ها و لجند را همان لحظه آپدیت می‌کند؛ حذف برنامه لایه، مقایسه را محترمانه خاموش می‌کند

### 👥 هم‌زمانی با دوستان

- لینک شیر دوست را paste کنید → بدون هیچ سروری:
  - آمار: دروس دوستتان، دروس مشترک، روزهای هم‌کلاسی
  - چیپ‌های دروس مشترک و فقط-دوست
  - **زمان‌های کلاس مشترک** هر روز — بازه‌های ساعت‌هایی که هر دو سر کلاسید + جمع ساعت
  - هشدار هوشمند وقتی درسی از دوستتان در دیتای شما وجود ندارد
- یا برنامه دوست را مستقیم **روی جدول** به‌صورت لایه مقایسه بگذارید

### 📤 خروجی‌ها و اشتراک (مدال واحد)

همه خروجی‌ها پشت **یک دکمه** جمع شده‌اند — دسکتاپ: دکمه «خروجی‌ها و اشتراک» در داک عمودی؛ موبایل: دکمه شیر در نوار شناور:

| کارت | کار |
|---|---|
| خروجی PDF | عکس جدول برای چاپ و آرشیو (با jsPDF، پشتیبانی کامل فارسی) |
| تقویم (ICS) | فایل استاندارد RFC 5545 با تکرار هفتگی — import در Google Calendar / iOS / Android |
| کپی برنامه | متن برنامه آماده ارسال در چت |
| لینک اشتراک | URL حاوی برنامه + تنظیمات ولیدیشن (base64 در hash) — بازکننده مودال «برنامه اشتراکی» می‌بیند و انتخاب می‌کند کدام دروس را وارد کند |
| خروجی JSON | کپی یا دانلود فایل کامل — برای بکاپ یا دادن به AI |
| تیک خودکار پورتال | اسکریپت کنسول سایت دانشگاه |
| ورود برنامه | paste کردن JSON یا انتخاب فایل ذخیره‌شده |

### 🧭 رابط کاربری

- **داک عمودی دسکتاپ** (کنار صفحه، شیشه‌ای): hover → به‌صورت کشویی باز می‌شود، نام هر ابزار نمایش داده می‌شود و بقیه المان‌ها نرم هل داده می‌شوند؛ پشتیبانی کامل کیبورد (Tab داک را باز نگه می‌دارد)
- **نوار عملیات موبایل**: FAB پایین صفحه → شیت عملیات با کاشی‌های لمسی + نوار دائمی undo/redo/شیر/هزینه/سطل
- **تم تیره و روشن** با یک کلیک (ذخیره‌شده در localStorage)
- **مودال‌ها در موبایل bottom-sheet** با گرابر و انیمیشن اسلاید از پایین
- فونت Vazirmatn روی **تمام** متن‌ها (شامل فرم‌ها، دکمه‌ها و باکس‌های کد)
- سیستم radius و رنگ یکدست با توکن‌های CSS (`--radius-*`، `--bg-*`، `--text-*` و…)
- لایه انیمیشن GSAP فقط برای presentation (ورود/خروج بلاک‌ها، toastها، شیت‌ها) — با `prefers-reduced-motion` و fallback کامل بدون GSAP
- بهینه‌سازی‌های performance: event delegation، ایندکس O(1) دروس، diff-render جدول (فقط بلوک‌های تغییرکرده)، debounce ورودی جستجو، DocumentFragment

## 🚀 اجرا

پروژه فقط از فایل‌های استاتیک تشکیل شده، اما به‌خاطر `fetch` فایل دیتا باید از طریق وب‌سرور باز شود (نه `file://`):

```bash
# مثال با Python
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

یا هر وب‌سرور استاتیک دیگر (Live Server در VS Code، `npx serve` و…).

**استقرار (GitHub Pages):** workflow `.github/workflows/deploy-react.yml` روی push به `main` اجرا می‌شود و فایل‌های `data/` را کنار خروجی build کپی می‌کند.

## 📁 ساختار پروژه

```
├── index.html              # صفحه اصلی (ساختار، ۱۵ مودال، داک دسکتاپ، نوار موبایل)
├── style.css               # استایل‌های اصلی (تم تیره/روشن، توکن‌ها، واکنش‌گرا)
├── features.css            # استایل فیچرهای جدید (مقایسه، هم‌زمانی، مدال خروجی‌ها، overlay)
├── combo.css               # استایل مودال هزینه و کارت‌ها
├── io.css                  # استایل مودال ورود/خروجی
├── validations.css         # استایل مودال ولیدیشن‌ها
├── script.js               # منطق برنامه (~۶۷۰۰ خط)
├── motion.js               # لایه GSAP (presentation-only، no-op بدون GSAP)
├── combo.js                # منطق مودال هزینه و اسکریپت پورتال
├── data/
│   ├── courses.txt         # دیتای دروس (جدول HTML پورتال)
│   ├── couresPrice.html    # جدول مبلغ واحد دروس
│   └── last-update.txt     # برچسب دستی تاریخ آخرین به‌روزرسانی دیتا
└── example.txt             # نمونه دیتا (fallback در نبود data/courses.txt)
```

## 🔄 به‌روزرسانی دیتا

1. جدول «دروس ارائه شده» را از پورتال آموزش دانشگاه کپی کنید (کل جدول HTML)
2. محتوای `data/courses.txt` را با آن جایگزین کنید
3. جدول مبلغ واحد را از پورتال کپی و در `data/couresPrice.html` جایگزین کنید
4. تاریخ را در `data/last-update.txt` به‌روز کنید (مثلاً `۱۴۰۴/۰۶/۱۱`)

تاریخ داخل `data/last-update.txt` در هدر برنامه نمایش داده می‌شود تا کاربر بداند دیتا چقدر تازه است. کاربران همچنین می‌توانند بدون دست زدن به فایل‌ها، از دکمه «دیتای دلخواه» دیتا را مستقیم وارد کنند.

|---|---|

| `unisel_dataset_exceptions` | دروس استثنا شده از دیتای دلخواه |
| `unisel_course_origins` | منشأ دروس (لینک شیر / دیتای دلخواه) |
| `theme` | تم فعلی (تیره/روشن) |

## 🎨 زبان طراحی

- رنگ‌بندی پایه: مشکی / سفید / خاکستری (neutral مدرن) — رنگ فقط جایی که **کارکرد** دارد: رنگ هر درس، حالت‌های موفقیت/هشدار/خطا، و لایه مقایسه
- فونت Vazirmatn با اعداد فارسی
- سطح‌بندی روشن: پس‌زمینه‌های تخت + حاشیه‌های ظریف به‌جای سایه‌های سنگین
- stateهای کامل: hover / active / selected / disabled / error / success / empty

## 🛠 فناوری

- HTML5 / CSS3 / JavaScript (ES6+) — بدون فریم‌ورک و بدون build step
- [GSAP](https://gsap.com) فقط برای انیمیشن (از CDN، با fallback کامل)
- [jsPDF](https://github.com/parallax/jsPDF) + [html2canvas](https://html2canvas.hertzen.com) برای خروجی PDF (از CDN)
- `localStorage` برای همه stateها
