# سیستم پیش‌انتخاب واحد دانشگاهی

ابزار تحت وب برای **پیش‌انتخاب (Pre-selection) واحدهای دانشگاهی** — ساخته‌شده با HTML، CSS و JavaScript خالص (بدون فریم‌ورک). کاربر دیتای دروس ارائه‌شده را وارد می‌کند، دروس را با فیلترهای پیشرفته جستجو می‌کند، و برنامه هفتگی خود را روی جدول زمانی تعاملی می‌چیند.

## ✨ امکانات

### جدول زمان‌بندی
- جدول هفتگی تعاملی (روزها × ساعات ۷ تا ۲۰) با چیدمان RTL
- بلوک‌های رنگی دروس با نمایش نام، استاد، ساعت و گروه — رنگ هر درس خودکار از پالت انتخاب می‌شود
- کشیدن و رها کردن نیست، اما کلیک روی بلوک جزئیات درس را باز می‌کند
- ردیف «سایر دروس» برای دروس بدون ساعت کلاس مشخص (کاراموزی، پروژه و…)
- تشخیص **تداخل زمانی** هنگام افزودن درس با نمایش مودال تداخل
- هشدار عبور از سقف واحد مجاز (۲۰ واحد)

### جستجو و فیلتر پیشرفته
- جستجوی زنده بر اساس نام درس، استاد، کد درس یا گروه
- چیپ‌های فیلتر روزهای هفته (چند انتخابی)
- فیلتر **ظرفیت آزاد** / **ظرفیت پر** (متقابل انحصاری)
- بازه ساعت (از/تا) و ساعت مشخص
- فیلتر استاد (لیست خودکار از دیتا)، تعداد واحد (شامل «۳ به بالا»)، و گروه
- مرتب‌سازی نتایج بر اساس نام درس (صعودی/نزولی)
- شمارنده فیلترهای فعال + دکمه حذف همه فیلترها

### انتخاب درس
- جمع واحدها و تعداد دروس انتخابی به‌صورت زنده
- نمایش ظرفیت هر درس (ثبت‌نام‌شده از ظرفیت) — سبز وقتی جا هست، قرمز وقتی پر است
- دروس با ظرفیت پر **قابل انتخاب نیستند** (دکمه غیرفعال + بج «ظرفیت پر» + بلاک در سطح منطق برنامه)
- ذخیره انتخاب‌ها در `localStorage` — با بستن مرورگر از بین نمی‌رود

### دیتای دلخواه
- ورود دیتای جدول HTML پورتال دانشگاه (کپی/پیست از سامانه آموزش)
- پارس خودکار: کد درس، گروه، واحد، ظرفیت، استاد و برنامه هفتگی از tooltipهای پورتال
- فعال‌سازی دیتای دلخواه، دیتای پیش‌فرض را قفل و همه انتخاب‌ها را پاک می‌کند
- دیتای دلخواه در `localStorage` ذخیره می‌شود و در اجرای بعدی بازیابی می‌گردد

### خروجی و ابزار
- **خروجی PDF** از جدول برنامه (تم روشن، پشتیبانی کامل فارسی با jsPDF)
- **کپی برنامه** در کلیپ‌بورد به‌صورت متن
- **حالت تمام‌صفحه** جدول با شبکه جابه‌جاشده (ساعت‌ها ردیف، روزها ستون) برای اسکرین‌شات — مناسب موبایل
- مودال اطلاع‌رسانی تازگی دیتا در هر بار باز شدن صفحه

### موبایل
- طراحی کامل واکنش‌گرا
- جستجو و فیلتر درون مودال مخصوص موبایل
- **داک شناور عملیات** در پایین صفحه (لیست دروس، PDF، کپی، دیتای دلخواه، ریست)
- شبکه جدول با اسکرول افقی نرم + حالت تمام‌صفحه فشرده

## 🚀 اجرا

پروژه فقط از فایل‌های استاتیک تشکیل شده، اما به‌خاطر `fetch` فایل دیتا باید از طریق وب‌سرور باز شود (نه `file://`):

```bash
# مثال با Python
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

یا هر وب‌سرور استاتیک دیگر (Live Server در VS Code، `npx serve` و…).

## 📁 ساختار پروژه

```
├── index.html              # صفحه اصلی (ساختار، مودال‌ها، داک موبایل)
├── style.css               # تمام استایل‌ها (تم تاریک نئوبروتالیسم، واکنش‌گرا)
├── script.js               # منطق برنامه (پارس دیتا، فیلترها، جدول، ذخیره‌سازی)
├── data/
│   ├── courses.txt         # دیتای دروس (جدول HTML پورتال)
│   └── last-update.txt     # برچسب دستی تاریخ آخرین به‌روزرسانی دیتا
└── example.txt             # نمونه دیتا (fallback در نبود data/courses.txt)
```

## 🔄 به‌روزرسانی دیتا

1. جدول «دروس ارائه شده» را از پورتال آموزش دانشگاه کپی کنید (کل جدول HTML)
2. محتوای `data/courses.txt` را با آن جایگزین کنید
3. تاریخ را در `data/last-update.txt` به‌روز کنید (مثلاً `۱۴۰۴/۰۶/۱۱`)

تاریخ داخل `data/last-update.txt` در هدر برنامه نمایش داده می‌شود تا کاربر بداند دیتا چقدر تازه است. کاربران همچنین می‌توانند از دکمه «دیتای دلخواه» خودشان دیتا را مستقیم وارد کنند.
